# Brand assets

`logo/` contains the transparent Codex Switcher mark. Its four PNG sizes are `logo-32.png`, `logo-64.png`, `logo-128.png`, and `logo-256.png`.

`app-icons/` contains the SVG source glyphs. `app-icons-64/` contains their transparent 64 × 64 PNG exports, grouped by icon name. Every asset uses the same blue-to-cyan signal language and has no background.
