# Codex Switcher — custom menu icons

18 independent SVG icons, each on a `256 × 256` transparent canvas. They use one visual language: a 16 px rounded outline, dark graphite foreground and blue-to-green signal accents. The files are intentionally not connected to the application.

Each icon also has a Windows ICO export at `ico/<icon-name>/icon.ico`. Every ICO contains 16, 24, 32, 48, 64, and 256 px frames; the surrounding generated platform sizes are kept with it for convenience.

Use the `*-accent.svg` files where an action needs emphasis; all others work as neutral menu glyphs.
